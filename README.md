## Running

- Obtain your AOC session cookie in the usual way.
  - Ensure the `SESSION_TOKEN` env var is set with this value.
- Run `main.go`. 
  - ⚠️ Be very careful to avoid spamming the AOC servers.
  - Recommendation is 900s between requests. This is your responsibility.
  - Remember to set the `USER_AGENT` env var with a way for Eric to contact you.
